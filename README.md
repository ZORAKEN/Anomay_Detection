# 💰 Expense Anomaly Detector

A Machine Learning project that detects unusual spending patterns in personal expense data using **Isolation Forest**.

## 🚀 Features

- Detect unusual expenses using Machine Learning.
- Analyze personal spending patterns.
- Visualize expense data.
- Upload and analyze transaction data.
- Interactive dashboard using Streamlit.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Matplotlib

## 📂 Project Structure

```text
expense-anomaly-detector/
│
├── app.py
├── detector.py
├── utils.py
└── README.md
```

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/saipapia/expense-anomaly-detector.git
cd expense-anomaly-detector
```

Install the required libraries:

```bash
pip install -r requirements.txt
```

## ▶️ Run the Application

```bash
streamlit run app.py
```

## 🧠 Algorithm

**Isolation Forest** is an unsupervised Machine Learning algorithm that identifies unusual data points by isolating them from normal observations.

In this project, it is used to identify potentially unusual expenses.

## 🎯 Objective

To apply Machine Learning techniques to personal finance data and identify unusual spending patterns.
